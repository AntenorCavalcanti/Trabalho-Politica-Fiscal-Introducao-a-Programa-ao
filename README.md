# 📊 Análise de Política Fiscal com Python & Pandas
Trabalho Acadêmico — Disciplina: Introdução à Programação

Este repositório contém o código-fonte, scripts de análise de dados e documentação do projeto final sobre Política Fiscal. O objetivo principal é utilizar a linguagem Python e o ecossistema Pandas para processar, analisar e visualizar dados econômicos e fiscais.

# 📌 Sobre o Projeto
A política fiscal desempenha um papel central na estabilização macroeconômica e no direcionamento de recursos públicos. Neste trabalho, aplicamos conceitos fundamentais de programação e manipulação de dados para analisar indicadores fiscais públicos.

Principais objetivos:

Limpeza, transformação e exploração de dados utilizando pandas.

Visualização de tendências, receitas, despesas e saldos fiscais.

Aplicação dos conceitos aprendidos ao longo da disciplina de Introdução à Programação.
